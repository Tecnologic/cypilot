# cypilot

Operator GUI and CLI for [UNIMOC](https://github.com/Tecnologic/unimoc) drives
and other Cyphal nodes: discovery with the node state at a glance, scanned
registers, enabling and stopping drives, recovery, plots across nodes and
triggered scope shots ([cymon](https://github.com/Tecnologic/cymon)).
Python on pycyphal, for Linux and Windows.

Work in progress.
